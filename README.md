# Resources to help make your own custom game carts for N64
Custom art for games or game mods and their respective resources.<br>
Other N64 tools, firmware backup and printer / label cutter Krita source files included in this repo.

## Cloning
* You must have Git-LFS to clone this repo
* git clone https://github.com/zezba9000/RetroMeUp64.OpenResources.git
* Or you can just download a zip if you have a GitHub account

### N64 Cart physical Label dimensions
* Front = 2.15 x 2.47
* Back = 3.09 x 1.5
* Nintendo Logo = 1.121 x 0.275
